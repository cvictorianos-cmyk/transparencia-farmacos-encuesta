PASO 3: Tu app/main.py (agregar endpoint)
  Copia este código al final de tu FastAPI app:

  ----
  from fastapi import BackgroundTasks
  import subprocess
  from datetime import datetime

  @app.post("/api/recolectar-navegador")
  async def recolectar_navegador(background_tasks: BackgroundTasks):
      def run_recolector():
          try:
              print(f"[{datetime.now()}] Iniciando Playwright", flush=True)
              result = subprocess.run(
                  ["python3", "scripts/recolectar_navegador_full.py",
                   "--export-json", "/tmp/navegador_hoy.json"],
                  capture_output=True, text=True, timeout=600
              )
              if result.returncode == 0:
                  subprocess.run(
                      ["python3", "scripts/integrar_navegador.py",
                       "/tmp/navegador_hoy.json"],
                      capture_output=True, text=True
                  )
                  print("[OK] Completada", flush=True)
          except Exception as e:
              print(f"[ERROR] {e}", flush=True)
      
      background_tasks.add_task(run_recolector)
      return {"status": "recolección iniciada (background)"}
  ----

  Commit & push:
      git add app/main.py
      git commit -m "feat: endpoint /api/recolectar-navegador"
      git push

================================================================================
❓ PREGUNTAS FRECUENTES
================================================================================

Q: ¿Puedo probar Playwright localmente?
A: No en sandbox (falta libc). Pero los scripts están listos. Deploy en Render
   y test via cron-job.org POST.

Q: ¿Qué pasa si Render no tiene espacio?
A: Playwright consume ~500 MB. Plan Starter de Render debería bastar.
   Monitorea: Render Dashboard → Deployments → Disk Usage.

Q: ¿Timeout si una clínica es lenta?
A: Sí. Cada página tiene timeout=10000 (10s). Si falla, aumenta a 20000 ms
   en recolectar_navegador_full.py línea ~130.

Q: ¿Cómo rollback si todo falla?
A: Pausa cron en cron-job.org. Sigue usando httpx (56 precios).
   Los scripts nuevos no afectan lo existente.

Q: ¿Puedo ejecutar manualmente para probar?
A: Sí, via curl:
   curl -X POST https://tu-api-render.onrender.com/api/recolectar-navegador
   Luego espera 5-10 min y verifica logs en Render.
